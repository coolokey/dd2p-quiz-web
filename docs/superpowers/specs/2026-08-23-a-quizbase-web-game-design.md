# A_QuizBase 雙人搶答網頁遊戲設計

## 目標

將舊版 Director／Flash 系統中的 `A_QuizBase` 題庫重製成可部署於 GitHub Pages 的雙人同機搶答網頁遊戲。第一階段僅處理四選一搶答模式，保留原始題庫文字與圖片資產。

## 使用流程

1. 首頁列出所有 `A_QuizBase` 題庫，教師選擇一份題庫。
2. 開始前選擇賽制：固定題數或限時制；再設定對應的題數或秒數。
3. 進入按鍵測試畫面，兩位玩家各自確認所有方向與答題鍵皆可被偵測。
4. 遊戲開始後，兩位玩家同時搶答。先按下答案鍵者取得該題作答權。
5. 答對者加 1 分；答錯不扣分，另一位玩家取得作答機會。
6. 題數完成或時間到即進入結算頁，顯示雙方分數、勝方與重新開始選項。

## 操作

| 玩家 | 移動鍵 | 答題鍵 |
| --- | --- | --- |
| 左方玩家 | `W`、`X`、`A`、`D` | `1`、`2`、`3`、`4` |
| 右方玩家 | 方向鍵 | `0`、`-`、`=`、`\\` |

按鍵測試畫面必須即時顯示每個已觸發按鍵，並避免瀏覽器快捷鍵干擾遊戲操作。

## 架構

- 前端採純 HTML、CSS、JavaScript，不使用伺服器端程式。
- 題庫轉換工具把每份原始 `A_QuizBase` 題庫輸出為 JSON。
- 圖片題維持引用原有 JPG 資產；文字題內容以 UTF-8 JSON 儲存。
- 遊戲核心分為題庫載入、賽制計時、鍵盤輸入、搶答狀態、計分與畫面渲染等獨立模組。
- GitHub Pages 僅提供靜態檔案，遊戲不蒐集、不傳送學生資料。

## 題庫處理範圍

第一階段支援 `A_QuizBase` 中的純文字四選一題與題幹／選項圖片題。題庫選單顯示所有有效題庫；空資料夾或缺少 `_para.txt` 的資料夾不顯示，並在轉換報表列為略過項目。

`.swf` 題庫無法直接由現代瀏覽器執行。第一階段的轉換工具需將其辨識並列入不支援清單，不假裝可玩；之後若要支援，需逐題重製內容。

## 錯誤處理與驗證

- 題庫缺少設定、題目、答案或圖片時，不可使整個網站中斷；該題庫應被停用並列出原因。
- 題庫轉換後需驗證題數、每題選項數、正確答案範圍及圖片檔存在性。
- 自動測試驗證賽制結束條件、搶答鎖定、答錯轉手、答對加分與兩套按鍵映射。
- 發布前在 GitHub Pages 實際驗證題庫選取、按鍵測試、兩種賽制與結算流程。

## 非目標

- 第一階段不含 `D_QuizBase` 配對題。
- 不含帳號、雲端戰績、班級名單或多人連線。
- 不嘗試在瀏覽器內執行 Flash／Director 二進位檔。

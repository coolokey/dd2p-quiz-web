# 115 年國中教育會考數學前十題題庫設計

## 目標

在題庫選單新增「國中教育會考」科目，提供一份「115 年國中教育會考數學第 1～10 題」題庫；該題庫進入遊戲後，題幹固定依第 1 題至第 10 題出現。

## 範圍

- 來源為官方 115 年國中教育會考數學科試題本與選擇題參考答案。
- 新增一份 10 題的 JSON 題庫與一筆題庫目錄資料。
- 第 2、6、8 題使用由官方題本擷取的必要圖表，以維持題意完整。
- 新題庫在題數制按第 1 題到第 10 題出題；限時制超過第 10 題後由第 1 題重新循環。
- 原題的四個選項文字與答案保持正確；遊戲既有的選項位置隨機機制仍會套用。

## 不在範圍內

- 不調整戰鬥流程、計分、輸入方式、畫面設計或其他題庫的出題行為。
- 不發布網站。

## 資料設計

題庫目錄新增一筆資料：

```json
{
  "id": "cap-115-math-01-10",
  "name": "115 年國中教育會考數學第 1～10 題",
  "subject": "國中教育會考",
  "questions": 10,
  "file": "./data/quizzes/cap-115-math-01-10.json"
}
```

題庫 JSON 使用既有題目欄位，並在根層新增 `questionOrder: "fixed"`。題目 ID 固定為 `001` 至 `010`，順序即為官方題號順序。

## 行為設計

出題準備函式接受題庫的 `questionOrder` 設定。設定為 `fixed` 時，複製題目陣列但不洗牌題目順序，再沿用既有機制重新配置每題正確選項的位置。未設定或設定為預設值的所有既有題庫，仍依現況洗牌題目與選項。

當固定題庫於限時制耗盡第 10 題時，下一輪再次依 `001` 至 `010` 建立，而非改為隨機排序。

## 驗證

- 題庫篩選測試確認「國中教育會考」顯示 1 份題庫。
- 出題器測試確認固定設定維持題目 ID 的原始順序，且選項洗牌後正確答案仍正確。
- 題庫資料測試確認題數為 10、題號為 `001` 至 `010`、每題為四選一，且答案與官方參考答案一致。
- 執行完整測試套件。

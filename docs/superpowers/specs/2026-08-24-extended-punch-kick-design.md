# 伸展式有趣拳腳設計

## 目標

讓所有角色的出拳與出腳不再只是整個人物衝撞，而是能明顯看見拳頭向對手打出去、腳沿弧線踢出去，並以有趣的漫畫節奏完成蓄力、出招、命中、受擊、收招及回位。

## 動作設計

- 出拳：角色後拉蓄力，伸展拳由角色前方快速向對手延伸，命中時拳頭短暫放大、出現速度線及「砰！」，接著拳頭縮回、角色回位。
- 出腳：角色下沉抬腳，伸展鞋沿向上的弧線踢向對手，命中時鞋底短暫放大、出現弧形軌跡及「踢！」，接著收腳、角色回位。
- 命中後沿用既有拳擊水平震退及踢擊向後上方翻倒兩種受擊反應。
- 左右玩家使用同一套標記，以方向 class 鏡像；中文字不得跟著鏡像反轉。
- 氣功維持既有投射物，不出現拳腳伸展圖形。

## 技術架構

- `buildAttackEffectMarkup()` 的 `weapon` 欄位在拳擊時產生 `.melee-strike.strike-punch`，踢擊時產生 `.melee-strike.strike-kick`；因此伸展拳腳從攻擊開始就存在，命中層仍只在 `impactDelay` 到達時顯示爆裂、傷害與受擊反應。
- CSS 以伸展軌跡動畫區分拳與腳：拳走水平直線、腳走上揚旋轉弧線；內層拳套／鞋子負責放大、旋轉及收回。
- 既有角色原始攻擊影格、角色突進、命中時間、音效、清理及 reduced-motion 行為全部保留。
- 手機版縮小拳腳尺寸與伸展距離，避免越出戰場或遮住題目。

## 驗證

- 單元測試確認拳、腳在攻擊層產生不同標記及文字，氣功不產生拳腳標記，左右方向正確。
- CSS 契約測試確認水平出拳、弧線踢擊、內層拳套／鞋子、收招、手機版及 reduced-motion 規則存在。
- 實機讓左右玩家各觸發拳與腳，確認伸出、命中、受擊、收回與清理依序完成。
- 完整測試須同時保證題庫分類、隨機攻擊、音效與對戰流程無回歸。

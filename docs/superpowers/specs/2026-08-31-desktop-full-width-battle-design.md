# 電腦版滿版戰場設計

## 目標

在非觸控電腦的寬螢幕上，讓戰鬥介面使用可用瀏覽器寬度，消除主畫面兩側大量深色空白；不更動行動裝置與所有輸入規則。

## 版面規則

- 僅套用於非觸控、寬度至少 1281 px 的桌機 viewport。
- `.battle-shell` 使用完整可用寬度與原有 10 px 內距，不再以 1280 px 置中限制。
- 戰場高度維持既有 `clamp(310px,47vw,570px)`，角色與題目區不縮放、不裁切。
- 行動觸控、鍵盤、USB 手把、暫停、音效與題庫規則均不變。

## 驗收

- 桌機寬螢幕的 `.battle-shell` 不再有 1280 px 最大寬度。
- 觸控橫向版仍保留原有 `.battle-shell` 寬度規則與側鍵／底鍵空間。
- 對應 CSS 測試與完整測試均通過。

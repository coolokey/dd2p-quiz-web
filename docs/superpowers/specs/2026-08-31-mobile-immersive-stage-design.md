# 行動橫向等比例沉浸戰場設計

## 目標

讓手機與平板的橫向戰鬥畫面像手遊一樣作為完整畫面等比例縮放，完整看見兩名角色的待機、拳擊、踢擊與受擊過程；不壓扁、不裁切人物或背景。

## 版面規則

- 僅在觸控裝置的橫向戰鬥介面套用。
- 對戰介面建立固定橫向遊戲畫布，依裝置可視寬高採 `contain` 邏輯等比例縮放；裝置比例不同時，以背景留白取代裁切或變形。
- 畫布中的戰場、角色、題目、答案與觸控按鈕一起縮放，維持已設計的相對位置；矮螢幕不再獨立壓縮戰場至 104 px。
- 角色保持 `object-fit: contain` 與底部對齊；校園場景使用 `background-size: contain` 與中央定位，完整顯示畫面。
- 題目與四個答案保留兩欄區；本機雙人觸控按鈕維持左右邊緣，單人觸控按鈕維持下方，並隨畫布縮放。

## 相容性

不更動題庫、答案亂數、戰鬥規則、音效、暫停、鍵盤、USB 手把、觸控輸入或直向轉橫向提示。

## 驗收

- 手機與平板橫向顯示時，人物、場景、題目與觸控按鈕均按同一比例縮放，且不裁切。
- 觸控答案仍為兩欄，雙人側鍵與單人底鍵的安全區預留仍存在。
- 背景不使用 `background-size: 100% 100%` 或 `cover`。
- 對應 CSS 測試與完整測試均通過。

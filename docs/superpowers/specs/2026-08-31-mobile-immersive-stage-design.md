# 行動橫向等比例沉浸戰場設計

## 目標

讓手機與平板的橫向戰鬥畫面依螢幕高度自適應，完整看見兩名角色的待機、拳擊、踢擊與受擊過程；不壓扁人物或背景。

## 版面規則

- 僅在觸控裝置的橫向戰鬥介面套用。
- 戰場優先分配約半數可視高度，在矮橫向裝置至少保留 190 px，不再降至 104 px。
- 角色保持 `object-fit: contain` 與底部對齊，將有效高度提高至約 88%，不改變原始圖片比例。
- 校園場景改用 `background-size: cover` 與中央定位，保留比例並允許必要裁切，禁止 `100% 100%` 拉伸。
- 題目與四個答案保留在戰場下方的兩欄區；本機雙人觸控按鈕維持左右邊緣，單人觸控按鈕維持下方。

## 相容性

不更動題庫、答案亂數、戰鬥規則、音效、暫停、鍵盤、USB 手把、觸控輸入或直向轉橫向提示。

## 驗收

- 矮橫向觸控裝置的戰場高度至少 190 px，人物顯示高度至少為角色舞台的 88%。
- 觸控答案仍為兩欄，雙人側鍵與單人底鍵的安全區預留仍存在。
- 背景不使用 `background-size: 100% 100%`。
- 對應 CSS 測試與完整測試均通過。

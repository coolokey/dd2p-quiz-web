# DD2P 首次載入效能設計

## 目標

讓第一次使用遊戲的新電腦與行動載具，能更快看到選角、場地與第一題，同時不改變題庫、戰鬥、音效、暫停、鍵盤、觸控或 USB 手把操作。

## 已核准的處理順序

1. 移除網頁內嵌的完整中文字型下載，改用裝置既有中文字型；保留小型的電競標題字型。
2. 將四張場地選擇縮圖改為 WebP，保留原始 PNG。
3. 將十二位角色的選角縮圖、待機圖與攻擊圖改為 WebP 執行版，保留原始 PNG。
4. 調整預載：優先下載戰場和兩位角色的待機圖；攻擊圖在遊戲已開始、瀏覽器有空時才下載，避免搶走第一題的網路頻寬。

## 驗收

- 首頁不再請求 NotoSansTC-Variable.woff2。
- 場地選擇與角色選擇引用 WebP 執行素材。
- 直接開始與鍵盤測試流程都仍可開局；預載先包含戰場與待機圖，攻擊圖延後。
- 保留 PNG 原始素材並通過既有完整測試。

# DDP 知識對決

以 `A_QuizBase` 題庫重製的知識搶答對戰網頁遊戲。網站為純靜態 HTML、CSS 與 JavaScript，可部署至 GitHub Pages。起始畫面可選擇「玩家 VS 電腦」或「本機雙人對戰」；網路連線對戰規劃為第二階段，目前尚未啟用。

## 遊戲方式

1. 在起始畫面選擇遊戲模式，再依科目挑選題庫。
2. 選擇固定題數制或限時制；單人模式可選 CPU 難度。
3. 從神殿、校園、船艦三個原版場景中選擇戰場。
4. 選擇角色，並可先測試鍵盤，或略過測試直接開始。
5. 先按答案鍵者取得作答權；答對加 1 分並使對手減少 10 HP，答錯不扣分、不扣血，另一方可再答。

### 玩家 VS 電腦

玩家使用左方紅隊；CPU 會從尚未被玩家選取的可用角色中隨機選擇右方藍隊角色。單人模式只需選擇左方角色，也只需測試左方鍵盤。

| CPU 難度 | 作答等待時間 | 答對率 |
| --- | --- | --- |
| 簡單 | 4～7 秒 | 50% |
| 普通 | 2.5～5 秒 | 70% |
| 困難 | 1.5～3.5 秒 | 90% |

玩家答對、題目換題、限時結束或離開對戰時，尚未作答的 CPU 計時會自動取消。若玩家先答錯，CPU 仍可在原題繼續作答；若 CPU 答錯，玩家仍可作答。

### 本機雙人對戰

兩位玩家使用同一台電腦、各自選擇角色；雙方不能使用同一名角色。可讓兩人分別完成鍵盤測試，也可略過測試後直接開始。

### 題目與正解

題目順序與選項都會隨機排列。正確答案位置使用「隨機且平均」的位置袋：同一種選項數量中，每一輪會讓各答案位置平均出現，且跨輪交界不會重複同一位置。若兩位作答者皆答錯，畫面會先揭示正確答案，再進入下一題；同一題交棒時不會重排選項。

雙方初始生命值為 100 HP。生命值歸零時立即以 KO 結束；題數或時間結束後依分數判定，平分則進入驟死題。三個場景各自搭配原版背景音樂，並包含搶答、答對、答錯、攻擊、命中、KO 與勝負音效；戰鬥畫面右上角可切換靜音。

| 玩家 | 移動鍵 | 答題鍵 |
| --- | --- | --- |
| 左方紅隊 | `W`、`X`、`A`、`D` | `1`、`2`、`3`、`4` |
| 右方藍隊 | 方向鍵 | `0`、`-`、`=`、`\` |

### 暫停與離場

對戰中可按畫面頂端「Ⅱ 暫停」，或使用鍵盤 `Esc` 開啟暫停選單。選單提供繼續遊戲、重新開始本局、更換題庫與返回首頁；重新開始本局、更換題庫與返回首頁都需要確認後才會執行。

## 行動載具

請以橫向畫面開始並進行對戰。進入戰鬥時，網站會在瀏覽器支援時嘗試鎖定為橫向；並非所有瀏覽器都允許程式鎖定方向，因此直向畫面會以旋轉提示作為備援。

若在對戰中轉為直向，系統會暫停目前戰鬥並封鎖作答輸入；可將裝置轉回橫向以繼續，或按「返回首頁」，系統會先顯示返回首頁確認，不會直接離開本局。單人模式會在畫面底部顯示一組四答案觸控按鍵；本機雙人對戰則分別提供左、右玩家各自的觸控按鍵。

實體鍵盤操作仍可使用，且按鍵對應維持不變：左方玩家使用 `1`、`2`、`3`、`4`，右方玩家使用 `0`、`-`、`=`、`\`。

## 本機執行

需要 Node.js 22 或更新版本。第一次建立或更新題庫／對戰素材時，依序執行以下命令：

```powershell
npm run prepare:battle
npm run convert
npm test
npm start
```

開啟終端機顯示的本機網址即可遊玩。日常只需執行 `npm start`；`npm test` 可執行自動化回歸。`npm run convert` 會從本機的 `A_QuizBase` 讀取題庫並重新建立 `web/data` 與 `web/images`。`npm run prepare:battle` 會從 `D_Unit/Game_03` 複製三個場景與背景音樂，並透過 `.tools` 內的 portable FFDec／Java 擷取 12 名角色、武器和音效；替換原始 SWF 後需重新執行此命令。

## GitHub Pages

推送至 GitHub 的 `main` 分支後，`.github/workflows/pages.yml` 會先執行測試，確認題庫與對戰素材存在，再部署 `web` 資料夾。題庫更新時，請先在本機執行 `npm run convert`；戰鬥素材更新時執行 `npm run prepare:battle`，並提交產生的網頁檔案。網路連線對戰不會隨本次 GitHub Pages 部署啟用，將在第二階段另行導入即時連線服務。

## 隱私

網站不讀取 `D_Dual`，不包含學生姓名、登入、雲端戰績或資料蒐集功能。

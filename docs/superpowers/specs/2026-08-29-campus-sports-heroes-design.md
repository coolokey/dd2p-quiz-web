# 校園社團英雄角色重製設計

## 目標

將現有十二位簡化角色替換為高完成度、可愛的原創 Q 版校園社團英雄。視覺品質參考使用者提供的 Q 版遊戲角色範例：大頭小身、清晰五官、立體髮型與服裝、明確戰鬥姿勢；不得使用或混淆為既有動漫的角色、名稱、標誌性服裝或招式。

## 視覺方向

- 主題：運動社團裝加上科技或魔法裝備。
- 比例：所有角色統一為約二點五頭身，透明背景、相同畫布尺寸及同一腳底基準線。
- 角色：全為原創人類，男女各六位。
- 品質：角色需有乾淨外輪廓、可辨識表情、層次分明的頭髮與服裝，適合選角畫面及戰鬥畫面縮放。
- 動作：每位提供待機圖與明確攻擊圖；攻擊圖須呈現前衝、揮拳或踢擊等大幅度姿勢，不能只改變特效。

## 遊戲相容性

下列機制不得變動：題庫與選項平均隨機、搶答規則、分數、電腦對戰、本機雙人、暫停與離場、音效、鍵盤、行動載具觸控、USB 搖桿、強制橫式提示、四個校園戰場。

角色資料仍使用既有 manifest 的 `states.idle`、`states.attack` 和 `attacks.energy/punch/kick` 介面；只更換素材及各角色的視覺設定，不能修改輸入映射或戰鬥狀態流程。

## 驗證

- 自動檢查十二名角色皆為人類、角色 ID 不重複、男女各六位、待機及攻擊素材均存在。
- 檢查所有素材畫布及腳底基準線一致，透明背景未被填色。
- 檢查四個場景、題庫、音效、鍵盤、觸控、USB 搖桿及暫停相關既有測試皆仍通過。
- 以桌機與行動橫式版實際檢視選角、攻擊、受擊及返回首頁流程。

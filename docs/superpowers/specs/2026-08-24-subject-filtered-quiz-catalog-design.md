# 題庫分科篩選設計

## 目標

將首頁原本平鋪的 31 份題庫依科目分類，讓使用者用「全部、數學、國文、英文、公民、歷史」按鈕快速篩選，同時保留目前選擇題庫後的所有流程。

## 分類規則

- 固定顯示順序為：全部、數學、國文、英文、公民、歷史、其他。
- 題庫轉換時就在 `catalog.json` 寫入 `subject`，首頁不靠臨時猜測名稱分類。
- 名稱含「國文、英文、公民、歷史、數學」時，依該明確科目分類；判斷國文必須優先於數學，確保誤寫為「(數學)國文 第三冊 文言文」的題庫仍歸入國文。
- `99`、`clock` 及 `math-`／`math_` 開頭的國小題庫歸入數學。
- 無法辨識者歸入「其他」；若數量為零，不顯示「其他」按鈕。
- 目前資料應得到：數學 23、國文 4、英文 2、公民 1、歷史 1，共 31 份。

## 首頁互動

- 預設選擇「全部」，顯示所有題庫。
- 每個篩選按鈕顯示科目名稱與題庫數量，例如「數學（23）」。
- 點擊科目後，立即重新顯示該科題庫卡片，並以明顯的選取狀態標示目前科目。
- 下方提示改為同時說明目前顯示數量與全部題庫數量。
- 題庫卡片的點擊、音效及後續規則／戰場／角色／鍵盤測試／對戰流程維持不變。
- 按鈕列可自動換行，窄螢幕不產生水平溢位。

## 架構

- `scripts/lib/quiz-subject.mjs`：提供題庫科目判定純函式，供轉換程序使用。
- `scripts/convert-a-quizbase.mjs`：產生含 `subject` 的目錄項目。
- `web/js/catalog-filter.mjs`：提供固定科目順序、計數、篩選及按鈕 HTML 等無 DOM 純函式。
- `web/js/app.mjs`：保存目前選取科目、渲染按鈕及綁定切換事件。
- `web/assets/app.css`：加入篩選按鈕、選取狀態及手機版換行樣式。

- 單元測試確認所有分類規則、目前 31 份題庫的各科數量、按鈕順序、零筆科目隱藏、篩選結果及 HTML 跳脫。
- 執行完整測試與轉換，確認 `catalog.json` 的每一筆都有合法 `subject`。
- 在桌面與窄螢幕實際點擊所有科目，確認數量、卡片、選取狀態及進入遊戲流程正確。
- 發布至 GitHub Pages 後，再於公開網址驗證相同流程。

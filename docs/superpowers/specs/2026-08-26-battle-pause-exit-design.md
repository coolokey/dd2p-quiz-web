# DDP 知識對決：對戰暫停與安全離場設計

日期：2026-08-26

## 目標

讓玩家在「玩家 VS 電腦」與「本機雙人對戰」進行期間，可以便利且安全地暫停、重新開始、更換題庫或返回首頁，不必依賴重新整理網頁，也不會因誤觸而遺失當前賽局。

## 已核准決策

- 採用頂端中央控制區的「Ⅱ 暫停」按鈕與中央暫停選單。
- 鍵盤 `Esc` 可開啟暫停選單，再按一次可繼續遊戲。
- 暫停選單包含「繼續遊戲」、「重新開始本局」、「更換題庫」與「返回首頁」。
- 「重新開始本局」、「更換題庫」及「返回首頁」都必須再次確認。
- 攻擊或受擊動畫期間收到暫停要求時，先完成該次攻擊、音效、扣血與計分，再自動進入暫停。
- 暫停期間背景音樂停止；繼續後從暫停前的播放位置恢復。

## 畫面與操作

### 常駐暫停入口

- 對戰頂端原有題目進度或剩餘時間必須保留。
- 「Ⅱ 暫停」按鈕放在頂端中央控制區，與進度資訊並列，不取代比分、題數或時間。
- 按鈕在電腦、平板與手機對戰中都顯示，並避開安全區、音量控制與觸控答案鍵。
- 按鈕提供可辨識文字及無障礙名稱，不只使用圖示。
- 非對戰畫面與賽後結算畫面不顯示暫停按鈕。

### 暫停選單

暫停後以模態遮罩覆蓋對戰畫面，背景仍可看見，但不能作答或操作戰鬥控制。選單依序提供：

1. 「繼續遊戲」：關閉選單並恢復原賽局。
2. 「重新開始本局」：顯示確認視窗。
3. 「更換題庫」：顯示確認視窗。
4. 「返回首頁」：顯示確認視窗，使用較明顯的離場警示樣式。

焦點進入選單後應停留在選單內，預設聚焦「繼續遊戲」。按下 `Esc` 的規則如下：

- 正常對戰：開啟暫停選單。
- 暫停選單：繼續遊戲。
- 離場確認視窗：取消確認並回到暫停選單，不直接恢復對戰。

### 二次確認

三項會放棄當前進度的操作各自顯示明確訊息：

- 重新開始本局：「目前分數、血量與題目進度將歸零。」
- 更換題庫：「目前對戰進度將不會保留，將返回題庫選單。」
- 返回首頁：「目前對戰進度將不會保留，將返回模式選擇首頁。」

每個確認視窗都有「取消」與清楚命名的確認按鈕。取消後只返回暫停選單，賽局仍保持暫停。

## 四項操作的結果

### 繼續遊戲

- 保留題目、題目順序、答案排列、比分、血量、剩餘時間與目前可作答玩家。
- 限時制從原剩餘秒數繼續。
- CPU 只以暫停前剩餘等待毫秒恢復，不重新抽選答案或完整等待時間。
- 背景音樂從暫停位置繼續。
- 只建立一個計時器與一個合法 CPU callback。

### 重新開始本局

- 保留遊戲模式、題庫、固定題數／限時規則、CPU 難度、場景及雙方人物。
- 分數、血量、題目進度、可作答狀態及驟死狀態全部重設。
- 建立新的賽局 session，重新隨機排列題目順序與各題答案位置。
- 重新播放開局音效並從第一題開始。
- 舊賽局的動畫、計時器與 CPU callback 全部失效。

### 更換題庫

- 停止目前賽局、動畫、CPU、計時器、背景音樂與方向控制。
- 保留目前遊戲模式：玩家 VS 電腦仍回到單人題庫選單，本機雙人仍回到雙人題庫選單。
- 清除目前題庫、規則、場景、人物選擇與賽局進度，讓玩家重新完成後續設定。

### 返回首頁

- 完整停止目前賽局與所有非同步活動。
- 清除遊戲模式、題庫、規則、場景、人物與賽局進度。
- 回到最初的「玩家 VS 電腦／本機雙人對戰」模式選擇首頁。

## 狀態架構

### 手動暫停狀態

在既有方向暫停與背景暫停協調器中加入獨立的 `manualPaused` 狀態。賽局只有在下列狀態全部解除後才能恢復：

- 非手動暫停。
- 非直向暫停。
- 頁面位於前景。

狀態轉換只透過單一暫停協調器執行，避免畫面按鈕、`Esc`、裝置旋轉及頁面切換各自建立不同的恢復路徑。

### 動畫期間的延後暫停

當作答 lifecycle 正在處理攻擊時，不中斷現有動畫 Promise。系統設定 `pauseRequested`，立即拒絕後續玩家與 CPU 輸入；待該次答案完成計分、扣血與畫面結算後，再切換成 `manualPaused` 並顯示暫停選單。

若該次攻擊已使賽局結束，直接顯示正式結算畫面並清除 `pauseRequested`，不再顯示暫停選單。

### 音訊

音訊管理器新增可恢復的暫停能力：

- 暫停目前背景音樂但保留播放位置。
- 繼續時只恢復原本正在播放且未靜音的背景音樂。
- 離場或重新開始時仍使用既有停止與重新選場音樂流程，不復活舊音軌。
- 已經開始的短攻擊音效允許隨該次動畫完成；正式進入暫停後不播放新戰鬥音效。

## 錯誤與競速處理

- 快速連按暫停按鈕或 `Esc` 不得重複建立遮罩、計時器或 CPU callback。
- 暫停期間所有觸控答案鍵與鍵盤答案鍵都被輸入閘門拒絕。
- 確認視窗顯示時，背景暫停選單也不可操作。
- 暫停後旋轉成直向，再按繼續時仍保留直向遮罩與暫停狀態；只有回到橫向且所有暫停原因解除後才恢復。
- 暫停後切到其他分頁，再回到前景時不得自動越過手動暫停。
- 重新開始、更換題庫或返回首頁後，舊動畫與非同步 callback 即使完成也不得修改新畫面。
- 音訊暫停或恢復遭瀏覽器拒絕時，遊戲狀態仍可正常暫停與繼續，並只在 console 留下可診斷訊息。

## 響應式與可及性

- 電腦與平板顯示「Ⅱ 暫停」完整文字；極矮橫式手機可縮小字級，但仍保留「暫停」文字。
- 按鈕最小觸控尺寸為 `48 CSS px`。
- 暫停與確認遮罩使用 `role="dialog"`、`aria-modal="true"` 及明確標題。
- 開啟選單時保存先前焦點；繼續後焦點回到暫停按鈕。
- 遮罩包含 `safe-area` 留白，且不產生水平捲動。

## 測試與驗收

### 自動化測試

- 單人與本機雙人對戰都產生暫停按鈕及四項選單功能。
- `Esc` 在正常對戰、暫停選單及確認視窗中符合三種既定行為。
- 手動暫停會停止輸入、限時 timer、CPU 等待與背景音樂。
- 繼續只恢復一個 timer 與一個 CPU callback，且保留剩餘時間。
- 攻擊動畫期間的暫停要求會在結算後執行；若賽局結束則直接進結果頁。
- 三種離場操作都需要確認，取消後保持暫停。
- 重新開始保留設定、建立新 session 並重設比分、血量與亂數題序。
- 更換題庫保留單人／雙人模式，但清除題庫以後的設定。
- 返回首頁清除完整模式與賽局狀態。
- 直向、背景及手動暫停可以疊加，且只有全部解除後才恢復。
- 現有鍵盤、觸控、攻擊動畫、答案隨機與音效測試持續通過。

### 瀏覽器驗收

- 電腦鍵盤與滑鼠、平板觸控及手機橫式皆可開啟和關閉暫停選單。
- 玩家 VS 電腦與本機雙人各完成一次暫停、繼續、重開、更換題庫及返回首頁流程。
- 暫停前後的比分、血量、題目、剩餘時間與可作答方一致。
- 攻擊動畫中按暫停不會造成卡住、重複攻擊、漏計分或多前進一題。
- 所有離場操作均無須重新整理網頁，且瀏覽器 console 沒有錯誤。

## 不包含項目

- 暫停後關閉瀏覽器，再次開啟時接續賽局。
- 儲存多局進度或建立玩家帳號。
- 網路連線對戰的暫停投票與房主權限。
- 修改題庫內容、攻擊傷害或 CPU 難度。

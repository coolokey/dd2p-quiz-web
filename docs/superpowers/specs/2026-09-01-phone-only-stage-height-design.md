# 手機橫向完整戰鬥舞台高度設計

## 目標

只修正手機橫向對戰畫面中戰場過矮、角色過小的問題；桌機與平板維持目前已驗證的畫面與操作。

## 根因與範圍

- 既有 `@media (orientation: landscape) and (max-height: 500px)` 對所有觸控裝置套用 `.arena` 最高 `180px` 與 `.fighter-sprite` 高度 `62%`，使手機在完整舞台縮放前就被壓縮。
- 此次只在手機型態的橫向對戰取消上述兩項壓縮；平板仍使用既有矮橫式規則。
- 手機以完整的戰場、角色、題目、答案與觸控鍵作為單一舞台，繼續使用既有縮放控制器計算比例。

## 保留行為

- 桌機不進入全螢幕、不套用行動縮放。
- 平板保持現有縮放與高度規則。
- 手機保留全螢幕、橫式鎖定、直向暫停、觸控作答、鍵盤、USB 手把、音效、暫停與戰鬥規則。

## 驗收

- 手機 `844 × 390` 橫向時，戰場不再受 `180px`／`62%` 規則限制，角色完整且明顯可見，題目與四個答案同時可見。
- 平板的既有 `.arena`／角色高度規則仍存在且未被手機修正覆蓋。
- 桌機 CSS 與方向控制流程不變。
- 自動測試全部通過。
